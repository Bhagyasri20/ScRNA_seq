# 🐍 Simple Python QR Code Generator

A short, lightweight Python script to instantly convert URLs or plain text into high-quality, scannable QR codes.

## 🚀 Features

- **Quick Generation:** Turn any website link or text into a QR code in seconds.
- **Auto-Save:** Saves the output directly to your local folder as a `.png` file.
- **Lightweight:** Uses minimal libraries to keep the code clean and fast.

## 🛠️ Requirements

Before running the script, make sure you have Python installed, along with the standard `qrcode` library and image support:

```bash
pip install qrcode
```

## 📦 How to Use

1. Clone or download this repository.
2. Run the script from your terminal:

```bash
python qrcode_gen.py
```
